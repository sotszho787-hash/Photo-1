# 光線診斷與工程相片驗收

這份參考只在分析複雜光線、決定是否加強窗光或輸出前驗收時讀取。

## 觀察表

| 觀察 | 保守處理 | 避免 |
| --- | --- | --- |
| 看見窗戶、景觀仍有細節 | 壓高光，微抬室內暗位 | 窗外換天空、假日落 |
| 看見窗戶但窗外已死白 | 保留曝光限制，修整過曝邊緣的刺眼感 | 從零生成樓景、樹影 |
| 窗在左側，有清楚左亮右暗 | 微量柔和左側亮度過渡 | 硬光條、窗格投影、假陽光 |
| 室內未見窗、僅頂燈 | 矯正偏綠偏黃，保留燈源亮度層次 | 當作有窗而加陽光 |
| 黃燈 + 日光同時出現 | 保留合理色溫差，局部平衡白牆 | 全圖黃、藍白櫃變灰 |
| 深木色櫃及天然木紋 | 溫和提亮暗部、減低飽和偏橙 | 畫出不存在的木紋、變更木材顏色 |
| 白色石材、灰色水泥 | 保住中性灰白、保留細紋 | 奶油黃濾鏡淹沒石紋 |

## 建議調整順序

1. 修正原相曝光與白平衡（先確認白牆是否偏色）。
2. 拉回高光以保住窗邊、白色櫃面和反射。
3. 平緩提亮暗位，保留深度感與天然陰影。
4. 輕微降低橙黃和綠偏色，但不破壞天然木系設計。
5. 真實窗戶與光向清楚才考慮微量柔光過渡；沒有就略過。
6. 以原相與輸出並排比較、100% 檢查。

## 100% 驗收清單

- 物件與雜物完全相同；不新增盆栽、花瓶、床品、燈具或任何裝飾。
- 櫃門條數、間隙、把手、裝置與櫃身輪廓完全相同。
- 牆、地、天花、窗框、瓷磚線及反射位置完全相同。
- 窗外風景、樓宇、樹木、天空內容完全相同（可改明暗，不能換景）。
- 木紋、石紋的真實走向沒有被改畫，材料呈現與實物相符。
- 直線及空間透視無變形，沒有透視校正造成的裁切（除非另獲准）。
- 光線方向和原相一致；不含新陰影、假光束、光斑、太陽直射區。
- 明度提升合理：白牆不刺眼，室內不灰霧、深木不漂白。
- 如原檔高光已完全丟失，明確告知不能保證回復細節。

## 可信度標示

- 程式式調色（本 Skill 腳本）：不增減或移動場景內容，但可能造成曝光高光壓縮、色彩偏移；仍要肉眼驗收。
- 生成式圖像編輯：即使提示保留原貌，仍可能改變櫃門、木紋和紋理；**嚴格忠實模式禁用**。
- 手動遮罩調光：品質取決於遮罩與操作；需對照原相驗證。
